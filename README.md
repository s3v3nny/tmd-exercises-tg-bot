# Бот с упражнениями для челюсти

Telegram-бот напоминает об упражнениях из [статьи wikiHow](https://www.wikihow.com/Treat-Temporomandibular-Joint-Disorder-(TMD)-with-Jaw-Exercises). Все сообщения и инструкции написаны на русском языке.

В статье для четырёх упражнений указано **6 повторений, 6 подходов в день**, но интервал между подходами не установлен. Бот отправляет один подробный набор упражнений каждые **2 часа 30 минут**, шесть раз за сутки. Первый подход происходит в выбранное время. Например, при начале в 08:00 уведомления приходят в 08:00, 10:30, 13:00, 15:30, 18:00 и 20:30. Если позднее начало переносит часть подходов за полночь, расписание показывает пометку «+1 день».

В каждом сообщении описаны четыре упражнения на 6 повторений. Дополнительно по ходу дня бот напоминает об отведении подбородка назад (10 раз в день), расслаблении челюсти, дыхании, осанке и двух упражнениях на подвижность, которые статья предлагает делать **по необходимости**. При боли упражнение нужно прекратить и обратиться к стоматологу или врачу.

## Запуск через Docker Compose

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Впишите токен в `TELEGRAM_BOT_TOKEN` в файле `.env`. При необходимости измените `DEFAULT_TIMEZONE` (часовой пояс для новых пользователей). `BOT_DB_PATH` должен указывать на файл внутри `/data`.
3. Запустите бота:

   ```bash
   docker compose up -d --build
   ```

Логи: `docker compose logs -f bot`. Остановка: `docker compose down`. База SQLite хранится в томе `bot-data` и сохраняется при остановке и пересоздании контейнера. Файл `.env` исключён из Git и из контекста сборки; `.env.example` содержит шаблон настроек без токена.

## Запуск без Docker

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите Python 3.10 или новее. Сторонние Python-пакеты не нужны.
3. Задайте переменную окружения и запустите:

   ```bash
   export TELEGRAM_BOT_TOKEN='токен_от_BotFather'
   python3 bot.py
   ```

Процесс должен работать постоянно. Данные сохраняются в `bot.sqlite3` в текущей папке. При необходимости путь задаётся через `BOT_DB_PATH`, а часовой пояс по умолчанию — через `DEFAULT_TIMEZONE` (по умолчанию `Europe/Samara`). Токен не добавляйте в репозиторий.

## Команды

| Команда | Действие |
| --- | --- |
| `/start 08:00` | Включить напоминания с указанным временем начала; `/start` использует 08:00 для нового пользователя |
| `/time 09:30` | Изменить начало |
| `/timezone Europe/Moscow` | Изменить часовой пояс (название из базы IANA) |
| `/status` | Посмотреть шесть времён уведомлений |
| `/exercises` | Посмотреть состав упражнений и частоту |
| `/pause`, `/resume` | Приостановить и возобновить уведомления |
| `/help` | Справка |

Бот отвечает только в личном чате. Просроченные более чем на пять минут уведомления пропускаются, чтобы после долгого отключения не отправлять сразу несколько старых сообщений. Уже отправленные подходы записываются в SQLite и не дублируются после перезапуска.
